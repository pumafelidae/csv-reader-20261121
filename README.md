A fast CSV reader with exactly csv-reader 1.0.0's answers: the same {columns, rows, errors} for every input, including broken rows (stray CRs, unterminated quotes, quote junk, short/long rows). Built on slices and indexOf instead of one character at a time — about 2x faster than the house baseline on the practice set.

## Run it

```sh
node main.ts
```
